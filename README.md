 LIVIT — PG & Co-Living UI/UX Website

LIVIT (Live In Verified Intelligent Tenancies) is a creative PG and co-living website designed and developed using HTML and CSS.

The project focuses on creating a modern, attractive, responsive, and user-friendly UI/UX experience for people looking for and managing PG accommodations.

🔐 Sign In & Sign Up pages

📝 Feedback and complaint sections
